# Roadmap

> Ideas and planned improvements for TokenTracker. No dates — shipped when ready.  
> Идеи и планируемые улучшения. Без дат — выйдет когда будет готово.

---

## Near-term / Ближайшее

- **Auto-update (Sparkle)** — in-app update notifications and one-click install when a new release is available
- **Global hotkey** — system-wide keyboard shortcut to show/hide the window without clicking the Dock
- **Per-project breakdown** — top projects by cost and tokens on the dashboard, grouped by Claude Code project folder
- **Bind local server to 127.0.0.1** — explicit localhost-only binding for the widget data server

---

## Medium-term / Среднесрочное

- **Monthly budget** — monthly spending limit with progress bar and alerts at 80% / 100%
- **Rate limit history** — chart showing 5-hour utilization over past days, not just token cost
- **Multiple accounts** — switch between personal and work Claude accounts without re-entering credentials
- **Light / system theme** — option to follow macOS appearance instead of always dark

---

## Longer-term / Долгосрочное

- **Anthropic API support** — track usage from direct API calls (via API key), not only Claude Code CLI
- **Period comparison** — "this week vs last week", "this month vs last month" with deltas
- **Full menu bar mode** — compact mini-dashboard in the menu bar only, no main window needed (à la Stats.app)
- **iOS companion widget** — iPhone / iPad widget showing the same data via iCloud sync

---

## Ideas / Идеи

- Weekly digest — short summary of your heaviest usage days, peak hours, most expensive project
- Team dashboards — opt-in aggregated stats across a team using Claude Code
- Linear / Jira integration — link Claude Code sessions to tickets by branch or project folder name
